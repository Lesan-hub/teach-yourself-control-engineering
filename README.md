# Teach Yourself Control Engineering｜控制工程自学指南

面向自动化、机器人工程及相关专业的控制工程自学路线。

[阅读完整指南](TeachYourselfControlEngineering-CN.md)

指南包含：

- 数学、编程、物理建模与信号系统基础
- 经典控制、状态空间、数字控制与实际实现
- 概率、系统辨识、状态估计与最优控制
- 非线性、MPC、鲁棒控制进阶入口
- 机器人、电机伺服、过程控制和 PLC 四个应用分支
- 每科官方在线资料、学习重点和验收任务
- 五个递进项目、52 周参考安排与第一周反馈实验

资料入口核对日期：2026-10-24。部分课程需要账号、选课或软件授权，具体访问条件见完整指南末尾。学习时间与任务为本指南编排建议。

组织形式参考 [TeachYourselfCS-CN](https://github.com/izackwu/TeachYourselfCS-CN)。外部教材和课程保留官方链接，使用时遵守各来源许可。
